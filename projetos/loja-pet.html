Loja online + API

Loja de rações, acessórios e medicações com retirada na loja ou entrega, painel administrativo e uma API pronta para um aplicativo.

Tipo
Loja online e API
Meu papel
Desenvolvimento, testes e documentação
Plataforma
Web, com API para app
Banco
PostgreSQL (Drizzle ORM)

O desafio

Vender medicamento veterinário pela internet tem regras: alguns só com receita na loja, controlados nunca podem aparecer. Além disso, a loja guarda dados pessoais (nome, telefone, CPF, endereço), então precisava estar de acordo com a LGPD e o Código de Defesa do Consumidor.

A solução

  • Mesmas regras para o site e para o app: o preço sempre vem do banco, o estoque é conferido de novo ao confirmar e medicamento com receita não entra no carrinho.
  • Dados pessoais criptografados no banco, com CPF mascarado no painel.
  • Painel para pedidos, produtos, estoque, mensagens e pedidos de titulares (LGPD).

Decisões técnicas

  • Next.js 15 com Server Components: as páginas da loja chamam os serviços direto no servidor.
  • Autenticação própria: cookie HttpOnly no site e token de 15 minutos com renovação no app, com detecção de reuso.
  • Segurança: CSP com nonce, proteção CSRF, limite de envios, papéis separados no banco e logs que não podem ser apagados.
  • Validação com Zod e testes das regras de negócio e da API.

No celular

Tecnologias

Next.js 15, React 19, TypeScript, PostgreSQL, Drizzle ORM, Zod, Motion e Docker.
