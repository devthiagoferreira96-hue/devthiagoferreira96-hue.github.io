# Portfólio — Thiago Proença

Site estático (HTML + CSS, sem build), publicado pelo GitHub Pages.

- `index.html`: página inicial com os projetos
- `projetos/`: um estudo de caso por projeto

Para ver localmente, abra o `index.html` no navegador.
